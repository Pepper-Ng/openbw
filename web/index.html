Interface Options

Input method

Automatic follows the active input device. Switching devices never changes your action-menu preferences.

Touch controls keep contextual taps. Mouse controls keep contextual right-clicks for movement, gathering, combat and repair.

Action buttons

Contextual essentials hides redundant worker actions. Full actions restores explicit buttons without changing contextual orders. Grids scroll when more than nine choices exist.

Size and visibility

UI size scales action buttons and gently scales resources. The minimap has its own size and stays independent of world zoom. Sizes adapt to available space. Mission timers and counters remain visible.

AttackBuild

Keyboard shortcuts

Bindings use physical key positions. Shift still queues ordinary actions. Custom bindings override the base profile; Grid assigns unused keys to other commands. Browser and system shortcuts cannot all be captured.
